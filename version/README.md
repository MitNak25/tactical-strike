# Tactical Strike versions

This directory contains playable HTML snapshots of the project.

## Current build

- [Tactical Strike V1.0 Prototype](./tactical_strike_V1.0%20-Release.html)

## Version policy

Version folders and release files are historical snapshots. Once a build is published, future gameplay changes should be added as a new version rather than silently replacing the old build.

## Running a build

From the repository root:

```bash
python3 -m http.server 8000
```

Then open the build in your browser:

```text
http://localhost:8000/version/tactical_strike_V1.0%20-Release.html
```
